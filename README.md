\# 1. 전 처리 과정



1 - 이미지 가져오기

   -  Hugging Face의 datasets 라이브러리를 통하여 오픈소스 데이터셋을 파이썬 코드로 불러옵니다.

2 - 크기 조정

   -  AI 모델은 입력 이미지의 크기가 통일되어야 하기 때문에 요구 사항에 맞추어 224 x 224로 크기를 조정해 주었습니다.

3 -  색상 변환

   - Grayscale: 색상을 0부터 255까지의 회색 명암으로만 표현하도록 바꿔줍니다.

   - Normalize (0~1): 모든 픽셀 값을 255로 나누어 범위를 0~1로 압축합니다.

4 - 노이즈 제거

   - Gaussian Blur 효과를 이용해 불필요한 노이즈를 제거하여 사물의 특징을 명확히 했습니다.

5 - 데이터 증강

   - flip 효과를 이용하여 데이터를 좌우 반전 시켰습니다.



\# 2. 심화 문제

이미지 크기 필터링 - 크기를 확인한 후 너무 작은 이미지(가로 또는 세로 100px 미만)를 자동 제외하였습니다.

평균 밝기 필터링 - numpy.mean을 통해 이미지의 평균 밝기를 계산하고, 기준치(50) 미만인 너무 어두운 이미지는 제거 하였습니다.
